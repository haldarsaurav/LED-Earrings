# Motion-water LED earrings

This repository contains a design-start package for a rechargeable pair of 8 × 10 RGB pixel earrings. The proposed first wearable revision adds an accelerometer so a blue waterline reacts to tilt. It is intended as a personal gift project.

**Build status:** EasyEDA now contains a partial schematic with five sourced symbols (MCU, accelerometer, charger, regulator and first LED) and a provisional 26 × 42 mm PCB outline with those five footprints. No electrical nets, 80-LED chain, final placement or routing have been completed. No hardware measurements or firmware compile/upload have been completed. The SVG, CSV and 3D models are studies, not files for fabrication.
